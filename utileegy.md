# utileegy
Python modules and scripts for EEG applications.

## Dependencies
`numpy` is required for each of the scripts, some have the additional dependencies detailed below.
```
pip install numpy
```

## BDF file interface
[bdf.py](bdf.py) provides a high-performance `numpy` read interface to data files encoded in the [BioSemi Data Format](https://www.biosemi.com/faq/file_format.htm). Returned 24-bit integer sample data are left justified within 32-bit words for compatibility with the `np.int32` data type. The `digimin` and `digimax` attributes of the file object are scaled to account for this. When working with raw data read from the Trigger Status channel note that these data are effectively left shifted by 8 bits.

See [bdf-examp.py](bdf-examp.py) for a usage example.

## Short Time Code modem
[stc.py](stc.py) implements a timing and metadata modem for use in conjunction with the EGG Audio Trigger Interface device. It allows for embedding of precise timing information and metadata in audio stimuli. This can be captured during EEG acquisition and subsequently analysed.

See [enc-examp.py](enc-examp.py) and [dec-examp.py](dec-examp.py) for encoder and decoder usage examples respectively.

The protocol is adapted from SMPTE Linear Time Code, utilising a fixed frame rate, shorter codeword, and frequency shift keying modulation. These revisions accommodate the low sampling rate and electromagnetic interference requirements of EEG, whilst providing convenient timestamp intervals and metadata bandwidth.

### Codeword format
Each STC codeword consists of 40 bits numbered 0 through 39. The bits are generated serially beginning with bit 0. Bit 39 of the codeword is followed by bit 0 of the next codeword. Each STC codeword contains the time address, binary user data, and a synchronisation word.

| Bit | Definition | Value |
| :---: | --- | --- |
| 0 - 3 | Units of frames | 0 - 9
| 4 - 7 | Units of seconds | 0 - 9
| 8 - 11 | Units of minutes | 0 - 9
| 12 - 15 | Units of hours | 0 - 9
| 16 - 19 | First binary nibble | 0 - fh
| 21 - 24 | Tens of seconds | 0 - 5
| 25 - 28 | Second binary nibble | 0 - fh
| 29 - 31 | Tens of minutes | 0 - 5
| 32 - 39 | Synchronisation word | ffh

The synchronisation word is static and can be used to accurately identify the bit position of the serial code. It is unique in that it cannot be generated by any combination of valid data values in the remainder of the code.

### Timing datum
The timing reference datum for STC is the zero-crossing point of the first transition of bit 0 of the 40-bit STC codeword.

### Bit rate
STC employs a fixed frame rate of 10 Hz. Consequently, the rate at which bits are generated is 40 bits × 10 Hz = 400 bps.

### Modulation method
The STC codeword is binary frequency shift keyed according to the following coding rules:
* A logical one is represented by one cycle of a 400 Hz tone.
* A logical zero is represented by a half cycle of a 200 Hz tone.
* The carrier phase is continuous across bit cell boundaries.

The resulting signal has no DC component, is amplitude and polarity insensitive, and includes transitions at every bit cell boundary from which the clock may be extracted.

The testbench [stc-tb.py](stc-tb.py) may be used to generate a visualisation.

## Audio to EEG data alignment
[audeega.py](audeega.py) performs time alignment of audio and EEG acquisition data for instances in which the audio signal has been routed to the EGG Audio Trigger Interface device. This enables time alignment of a live audio recording or indeed an audio stimulus signal, though it is recommended that stimulus be augmented with a Short Time Code track for the purposes of synchronisation.

The tool will report usage help if invoked with the `--help` option. By way of example:

To determine the timing offset between the EEG and audio data files `voicetrig.bdf` and `voicetrig.wav` run:
```
python audeeg.py voicetrig.bdf voicetrig.wav --figures
```
This will report the numerical timing offset and plot the cross-correlation along with the aligned trigger and audio data.

### Additional dependencies
`scipy` and `matplotlib` are required.
```
pip install scipy matplotlib
```

## Auditory Brainstem Response stimuli generation
[abrstim.py](abrstim.py) is an analytic sawtooth waveform synthesiser which may be used to generate stimulus to evoke an auditory brainstem response. The tool generates a WAV file in which the amplitude, fundamental frequency, polarity, number of harmonics, number of repetitions, and sampling rate may be set. By default, these are -12.0 dBFS, 128.0 Hz, positive, 32, 128, and 48000 Hz respectively. The onset and offset of the signal are half-cosine windowed over a single period of the fundamental frequency. Note that the fundamental frequency must be a factor of the audio sampling rate, it should also be a factor of the EEG sampling rate for synchronous analysis.

The tool will report usage help if invoked with the `--help` option. By way of example:

To generate default stimuli with positive and negative polarities and number of repetitions 2000 run:
```
python abrstim.py --repetitions 2000
python abrstim.py --repetitions 2000 --invert
```
This will generate the files `abrstim-pos.wav` and `abrstim-neg.wav`, each with duration 2000 / 128.0 Hz = 15.625 seconds.
