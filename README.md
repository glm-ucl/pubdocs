# pubdocs

Public documentation for various hardware and software developments.

* Electroencephalography (EEG)
  - [eegtrig.md](eegtrig.md) - Biosemi EEG audio trigger interface hardware.
  - [utileegy.md](utileegy.md) - Python modules and scripts for EEG applications.
* Electromagnetic Articulography (EMA)
  - [ema-tools.md](ema-tools.md) - NDI Vox-EMA data collection and analysis support tools.
  - [ema-trans.pdf](ema-trans.pdf) - EMA data transformation and rigid body registration technical note.
* Transcranial Magnetic Stimulation (TMS)
  - [tmstrig.md](tmstrig.md) - TMS trigger controller hardware.
